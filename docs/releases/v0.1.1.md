# Naver Maps MCP Server v0.1.1

This release aligns the Linux installer and bundle with the Naver Maps MCP
Server project name. It includes a gateway, a lazy Java/Selenium worker, and a
user-systemd service.

## Included

- `naver_map_search` for keyword searches and `naver_map_coordinate_search` for
  coordinate searches.
- A Linux x86-64 release bundle and a curl installer.
- Bearer authentication by default and user-systemd service setup.
- OpenAI Secure MCP Tunnel deployment instructions.
- An installer migration that preserves an existing bearer token and stops the
  previously installed service.

## Requirements and limitations

- Linux x86-64, Java 17 or newer, current stable Chrome or Chromium, and a
  ChromeDriver with a matching major version.
- Naver browser automation relies on an external web UI and can be intermittent.
- The management CLI and self-update workflow are not part of this release.
